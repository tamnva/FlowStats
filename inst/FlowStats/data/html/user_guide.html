Welcome!

FlowStats is a tool for streamflow visualization and statistical analyses for Germany based on DWD data and LSTM rainfall-runoff model. This includes the most up-to-date and near-future streamflow forecasts (up to 5 days ahead).

The current color of the gauged is visualized based on the performance of the LSTM model for the test period (2010-2020).

Please following steps when using this app: Update data (optional) → Single gauge → All gauges.

  1. Update data: This is optional, to get lastest and near future meterological data from DWD and run the LSTM model. Otherwise the data is taken from the base data in this tool from 01.1980 - 5.2025.
  2. Single gauge: Visualize streamflow at an individual gauge—through time series, yearly cycle time series, or cumulative yearly cycle time series—by clicking the gauge location on the Leaflet map.
  3. All Gauges: Visualize statistical streamflow indices for all gauges (note: computationally intensive →).
