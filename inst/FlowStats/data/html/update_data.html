To update data, FlowStats will download the historical meterological data from DWD and forecast meterological data from DWD ICON-D2 (0-48 hours) and ICON-EU (49-120 hours) using R and then run the LSTM model using Python. What FlowStats needs is the virtual python environment to run the LSTM model.

Therefore, user need to create the python virtual environment using this environment file and then provide the path to this environment in the field "Provide Python virtual environment".

More information about create a virtual environment from an environment file can be found here

Please RERUN this app after updating is done.
